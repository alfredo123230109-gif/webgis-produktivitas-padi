# webgis-produktivitas-padi
WebGIS Estimasi Produktivitas Padi - Lampung Tengah 🌾  Proyek ini adalah dashboard WebGIS interaktif yang dikembangkan sebagai luaran penelitian skripsi. Bertujuan untuk memvisualisasikan estimasi hasil panen padi secara spasial dan temporal (Tahun 2020, 2022, dan 2024) di wilayah Kabupaten Lampung Tengah.
